START HERE One minute

What this is

You may have used Claude or ChatGPT in a browser: you type, it answers. Claude Code is the same intelligence, but it can act. It lives on your computer, sees the files in a folder you choose, and can create, edit, organize and build things there.

In the browser

Claude, the chat

Like a consultant on the phone. Gives you advice and drafts; you do the doing.

On your computer

Claude Code

Like a capable resident. Does the work itself, shows you what it did, and asks when unsure. You supervise.

Things it's genuinely good at for someone like you. You'd say, in plain words:

  • Read the twelve PDFs in this folder and give me a one-page summary of each.
  • Turn these lab exports into one clean spreadsheet with a chart.
  • Draft a referral letter template I can reuse, in my tone.
  • Build a simple website for the clinic: hours, location, a contact form.
  • Rename and sort these 400 photos by date into folders.
  • Every Monday I copy numbers from one file to another. Do it for me.

Two words you'll see. Terminal is a plain text window where you can type instructions to your computer. You won't need it beyond pasting one line when Claude asks. Prompt just means a message you send to Claude.

One rule before anything else. Claude Pro and Max are not set up for patient records (there's no HIPAA agreement on those plans). Keep names, dates of birth and anything identifying out of the files and chats, or de-identify first. Everything else is fair game.

STEP 1 Have these ready · 5 min

Three things to have ready

  • A Claude account on the Pro or Max plan. Claude Code is included in both. Pro is the entry plan; Max is for people using it for hours a day. Sign up or upgrade at claude.com/pricing.
  • A PC running Windows 10 or 11. To check: open Settings from the Start menu, then System, then About.
  • Permission to install programs on it. On your own PC you have it. On a hospital- or practice-managed laptop, installs are often blocked; if so, ask your IT person to install the Claude app for you, or use a personal PC.

Along the way Windows will ask a few times, Do you want to allow this app to make changes to your device? That's normal. Click Yes.

STEP 2 Install the app · 3 min

Install the Claude app

  1. Go to claude.com/download and choose the Windows version.
  2. Open the downloaded installer and let it run. If Windows asks whether to allow changes, click Yes.
  3. Open Claude and sign in with your account.
  4. At the top of the window, click the Code tab. That's Claude Code.

There's also a version that runs in a plain text window (PowerShell). You don't need it today; Part 2 installs it quietly for later.

STEP 3 Pick a folder · 1 min

Pick a folder to work in

Claude Code works inside one folder at a time. It can see and change what's in that folder and nothing outside it.

  1. Open File Explorer (the yellow folder icon in the taskbar), go to Documents, and make a new folder called Claude. If your Documents folder lives in OneDrive, that's fine.
  2. Back in the Code tab, when it asks which folder to open, choose that one.
  3. If it asks whether you trust the folder: yes. It's yours.
STEP 4 Look around · 2 min

What you're looking at

  • The chat box at the bottom. You type here; Enter sends.
  • The mode setting next to the send button (or press Ctrl+Shift+M). Auto means Claude does the work and tells you what it did, with built-in safety checks. Manual means it asks before each action. Leave it on Auto.
  • The side panels. One shows files Claude changes; one is a Terminal, which Ctrl+` shows or hides. You'll only use the Terminal when Claude hands you a line to paste.

When Claude does ask permission, it looks like this. 1 means yes. 2 means yes, and stop asking for this kind of thing. 3 means no, and you tell it what to do instead.

Command
winget install JohnMacFarlane.Pandoc
Install pandoc so I can convert Word documents to other formats
Do you want to proceed?
❯ 1. Yes
  2. Yes, and don't ask again for winget install commands in this project
  3. No, and tell Claude what to do differently (esc)

Say hello (optional)

Type this into the chat box and press Enter:

  • Hi. I'm a doctor and completely new to this. In three sentences, what can you do for me?

Read the answer. That's the whole interface: you talk, it works.
